1\. Что нужно знать

<note type="info">

**Требование стандарта**

Все модели проекта должны иметь согласованную систему общих координат. Для передачи координат используется координационная модель. Каждая связь формата NWC, RVT, IFC и DWG, загруженная в 3D, размещается в отдельном рабочем наборе.

</note>

-  Связи используются для совместной работы моделей разных разделов без копирования элементов в текущий файл.

-  Положение связей определяется единой системой координат проекта, а не визуальным совмещением на глаз.

-  Отдельный рабочий набор для каждой связи позволяет управлять ее загрузкой, видимостью и производительностью модели.

-  На рабочих видах видимость связей настраивается по назначению вида; на экспортном виде «Navisworks» все связанные модели и DWG-подложки должны быть скрыты.

<note>

**Важно**

Стандарт задает правила координат, рабочих наборов, именования и итоговой проверки. Пошаговые действия в интерфейсе Revit ниже приведены как практический порядок выполнения этих требований.

</note>

2\. Форматы внешних данных

| **Формат** | **Назначение в проекте**                                                                  | **Рабочий набор**                |
|------------|-------------------------------------------------------------------------------------------|----------------------------------|
| RVT        | Модель Revit другого раздела или части объекта.                                           | (96)\_RVT_Имя файла              |
| DWG        | 2D- или 3D-данные AutoCAD; при загрузке в 3D размещаются в отдельном рабочем наборе.      | (97)\_DWG_Имя/Раздел_Комментарий |
| IFC        | Открытый обменный формат для моделей из стороннего программного обеспечения.              | (98)\_IFC_Имя/Раздел_Комментарий |
| NWC        | Координационные данные Navisworks, используемые как внешняя модель для проверки и увязки. | (95)\_NWC_Имя файла              |

<note type="lab">

**Особенность исходного стандарта**

В общей таблице рабочих наборов указан код (95) для NWC. В подробной таблице примеров отдельно приведены коды (96)–(98) для RVT, DWG и IFC.

</note>

3\. Правила рабочих наборов

**Одна связь -- один рабочий набор.** Не объединяйте несколько файлов, даже одного раздела, в один рабочий набор.

**Код формата обязателен.** Имя рабочего набора начинается с установленного цифрового кода.

**Имя должно идентифицировать файл.** По рабочему набору должно быть понятно, какой файл или раздел в нем находится.

**Рабочий набор создается до загрузки.** Это снижает риск размещения связи в текущем или случайном рабочем наборе.

**При замене файла проверьте имя.** Если изменилось имя связанного файла, рабочий набор также должен оставаться однозначно понятным.

Схема назначения рабочего набора выбранной связи

4\. Загрузка связи RVT

**1\. Подготовьте рабочий набор.** Создайте рабочий набор вида «(96)\_RVT_Имя файла» и сделайте его текущим перед загрузкой.

**2\. Откройте загрузку.** Вкладка «Вставка» -> «Связь Revit» и выберите согласованный файл модели.

**3\. Выберите способ размещения.** После настройки общих координат применяется размещение «По общим координатам». Для первичной координации следуйте схеме, принятой BIM-координатором проекта.

**4\. Проверьте тип ссылки.** Используйте «Наложение», если связанная модель не должна передавать свои вложенные связи в текущий файл; иной вариант применяется только по принятой схеме проекта.

**5\. Проверьте свойства.** Убедитесь, что экземпляр связи находится в правильном рабочем наборе и не продублирован.

**6\. Закрепите связь.** После проверки положения закрепите экземпляр, чтобы исключить случайное перемещение.

<note type="info">

**Способ первичного размещения**

Исходный стандарт требует согласованных общих координат, но не устанавливает единственный способ самой первой вставки файла. Первичную загрузку и передачу координат выполняйте по инструкции BIM-координатора проекта.

</note>

Схема окна загрузки связи Revit

5\. DWG, IFC и координационные модели

| **Формат** | **Практический порядок работы**                                                                                                                                                            |
|------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| DWG        | Для обновляемых исходных данных используйте связь САПР. Проверьте единицы, позиционирование и режим «Только текущий вид» для 2D-подложек. 3D-DWG поместите в отдельный рабочий набор (97). |
| IFC        | Загрузите как связь IFC, назначьте рабочий набор (98), проверьте единицы и координаты. Изменения выполняются в исходной модели и затем обновляются в Revit.                                |
| NWC        | Добавьте как координационную модель, назначьте рабочий набор (95) и используйте для визуальной увязки. Координационная модель не заменяет проектную RVT-связь.                             |

<note type="tip">

**Практическая рекомендация**

Не импортируйте обновляемые внешние данные в модель, если задача решается связью. Связь проще обновлять, отключать и контролировать через рабочий набор.

</note>

<note type="info">

**Чертежные 2D-данные**

Стандарт допускает выполнение отдельных узлов на чертежном виде или через связь DWG. Такие данные должны использоваться только в предусмотренных для них видах.

</note>

6\. Общие координаты

-  Все модели должны иметь единую согласованную систему координат, включая абсолютные и относительные отметки и направление истинного севера.

-  Источником координат является согласованный исходный файл; для передачи координат используется координационная модель.

-  Точка съемки должна соответствовать базовому файлу, а координаты моделей -- быть согласованы между собой.

-  После загрузки сравните оси, уровни, базовую точку и ключевые геометрические элементы со смежными моделями.

<note>

**Не перемещайте связь вручную после координации**

Если модель не совмещается по общим координатам, не исправляйте это перемещением или поворотом экземпляра. Зафиксируйте проблему и передайте BIM-координатору.

</note>

Схема передачи единой системы координат между моделями

7\. Обновление и замена связей

**Обычное обновление.** Откройте «Управление связями», выберите файл и выполните «Перезагрузить».

**Изменился путь или имя файла.** Используйте «Перезагрузить из…», укажите новый файл и затем проверьте рабочий набор и координаты.

**Временное отключение.** Выгружайте связь через «Управление связями» либо отключайте ее рабочий набор при открытии модели.

**После обновления.** Проверьте положение, уровни и оси, наличие дубликатов, закрепление экземпляра и видимость на рабочих видах.

**Удаление.** Удаляйте связь только когда она больше не используется в проекте и это согласовано с BIM-координатором.

<note>

**Не удаляйте и не вставляйте заново без необходимости**

При повторной вставке можно потерять настроенную видимость, переопределения, рабочий набор и проверенное положение экземпляра.

</note>

8\. Видимость связей

**На рабочих видах.** Настраивайте видимость связей в соответствии с назначением вида и утвержденным шаблоном вида.

**На координационных видах.** Показывайте только те модели и категории, которые нужны для проверки текущей задачи.

**Через рабочие наборы.** Используйте рабочие наборы для загрузки и глобального отключения тяжелых или временно ненужных связей.

**На виде «Navisworks».** Все связанные модели и DWG-подложки должны быть скрыты, чтобы в экспорт не попадали повторно элементы смежных разделов.

<note type="info">

**Единообразие настроек**

Видимость связей, импортированных категорий и координационных моделей рекомендуется закреплять в шаблонах видов, а не настраивать вручную на каждом виде.

</note>

| **Ситуация**                                 | **Действие**                                                                           |
|----------------------------------------------|----------------------------------------------------------------------------------------|
| Связь не нужна в текущем сеансе              | Выгрузить или отключить ее рабочий набор при открытии модели.                          |
| Связь нужна только на отдельных видах        | Оставить загруженной и управлять видимостью через шаблон вида.                         |
| Нужно показать только часть связанной модели | Использовать настройки отображения связи на виде и согласованный вид связанной модели. |
| Экспорт собственной модели в NWC             | Скрыть все связи и DWG-подложки на виде «Navisworks».                                  |

9\. Запрещенные действия

<note type="danger">

**Запрещено требованиями проекта**

Размещать несколько внешних файлов в одном рабочем наборе; нарушать кодировку рабочих наборов; передавать модели с несогласованными координатами; вручную перемещать скоординированные связи; повторно вставлять модель вместо обновления; заменять координационный файл без согласования; оставлять связи и DWG-подложки видимыми на виде «Navisworks».

</note>

10\. Проверка перед синхронизацией и передачей

| **Проверка**                                                      | **Результат**  |
|-------------------------------------------------------------------|----------------|
| Каждая связь загружена один раз и находится в проектном положении | Да / исправить |
| Координаты, оси и уровни согласованы с координационной моделью    | Да / исправить |
| Каждая связь находится в отдельном рабочем наборе                 | Да / исправить |
| Код и имя рабочего набора соответствуют формату файла             | Да / исправить |
| Связи закреплены после проверки положения                         | Да / исправить |
| Пути к файлам актуальны, отсутствуют потерянные связи             | Да / исправить |
| Видимость связей настроена через шаблоны видов                    | Да / исправить |
| На виде «Navisworks» скрыты все связи и DWG-подложки              | Да / исправить |
| Передаваемые модели очищены и скоординированы друг с другом       | Да / исправить |

<note>

**При обнаружении смещения**

Не исправляйте положение связи самостоятельно. Зафиксируйте имя файла, вид, величину и направление смещения и передайте информацию BIM-координатору.

</note>
