## 1\. Что нужно знать

<note type="info">

**Рабочий набор**

Группа элементов Revit, используемая для распределения прав редактирования и управления видимостью объектов модели. В совместной модели конкретный элемент одновременно принадлежит только одному рабочему набору.

</note>

-  Рабочие наборы обеспечивают коллективную работу через центральное хранилище и рабочие копии пользователей.

-  Набор выбирается по назначению элемента: геометрия раздела, базовые элементы, отверстия, временные элементы или внешние связи.

-  Список рабочих наборов определяется для конкретного проекта. В названии обязательно должна присутствовать кодировка.

-  Одинаковые названия общих рабочих наборов помогают управлять видимостью осей, уровней, отверстий и других общих элементов в связанных моделях.

## 2\. Порядок работы

*Рекомендуемый цикл работы с моделью*

**Откройте модель штатным способом.** Работайте в пользовательской рабочей копии/кэше, связанной с центральным хранилищем. Не создавайте отсоединенную копию без указания BIM-координатора.

**Проверьте активный рабочий набор.** Перед созданием элементов убедитесь, что в строке состояния выбран набор вашего раздела или нужной группы элементов.

**Создавайте и редактируйте элементы.** Назначайте элементы в соответствии с таблицей проекта. По возможности заимствуйте отдельные элементы, а не весь рабочий набор.

**Синхронизируйтесь с центральным хранилищем.** Выполняйте синхронизацию после завершения логического блока работы и перед закрытием модели.

**Освободите занятые элементы.** При завершении работы освободите все принадлежащие вам элементы и рабочие наборы.

<note>

**Важно**

Неправильно выбранный активный рабочий набор приводит к массовому попаданию новых элементов не в ту группу. Проверяйте активный набор перед началом моделирования и после переключения между задачами.

</note>

## 3\. Коды и назначение рабочих наборов

| **Код**  | **Группа**       | **Назначение и примеры**                                                                    |
|----------|------------------|---------------------------------------------------------------------------------------------|
| **(10)** | АР               | (10)\_АР; стены, витражи, кровля, полы, ограждения, окна, двери.                            |
| **(20)** | КР / КЖ / КМ     | (20)\_КР; стены, перекрытия, лестницы и другие конструктивные элементы.                     |
| **(30)** | ИОС              | (30)\_ОВ, (30)\_ВК, (30)\_ПТ и др.; оборудование, сантехнические приборы, отверстия.        |
| **(40)** | ТХ               | (40)\_ТХ; технологические элементы и оборудование.                                          |
| **(50)** | Прочее / скрытое | (50)\_Temp -- элементы, не отображаемые на видах; (50)\_Имитация -- имитационные элементы.  |
| **(60)** | АИ               | (60)\_АИ; отделка стен, полы, потолки, сантехника, оборудование, перегородки, двери.        |
| **(95)** | Связи NWC        | (95)\_NWC_Имя файла -- отдельный набор для каждой связи NWC.                                |
| **(96)** | Связи RVT        | (96)\_RVT_Имя файла -- отдельный набор для каждой связи Revit.                              |
| **(97)** | Связи DWG        | (97)\_DWG_Имя/Раздел_Комментарий -- отдельный набор для каждой DWG-связи.                   |
| **(98)** | Связи IFC        | (98)\_IFC_Имя/Раздел_Комментарий -- отдельный набор для каждой IFC-связи.                   |
| **(99)** | Базовые элементы | Оси, уровни, области видимости и служебный набор для элементов с неопределенной категорией. |

<note type="info">

**Правило для связей.**

Каждая связь NWC, RVT, DWG или IFC размещается в отдельном рабочем наборе. Это позволяет отключать ее при открытии модели и управлять загрузкой независимо от других связей.

</note>

<note>

**Уточнение по осям и уровням**

В исходном стандарте приведены два варианта именования: объединенный набор вида «(99)\_АР_Оси и уровни» и раздельные наборы «(99)\_Уровни АР» / «(99)\_Оси АР». На проекте следует применять вариант, уже закрепленный в шаблоне или Плане выполнения ЦИМ. **Самостоятельно переименовывать эти наборы нельзя.**

</note>

## 4\. Куда помещать элементы

| **Элемент**                         | **Рабочий набор**                                              |
|-------------------------------------|----------------------------------------------------------------|
| **Основная геометрия раздела**      | Рабочий набор раздела: (10), (20), (30), (40) или (60).        |
| **Оси и уровни**                    | Базовый набор (99), принятый на проекте.                       |
| **Области видимости**               | (99)\_Области видимости.                                       |
| **Отверстия АР / КР / ИОС**         | Соответствующий набор отверстий, например (30)\_Отверстия ИОС. |
| **Временные и скрываемые элементы** | (50)\_Temp.                                                    |
| **Имитационные элементы**           | (50)\_Имитация.                                                |
| **Связь Revit**                     | (96)\_RVT_Имя файла.                                           |
| **Связь DWG**                       | (97)\_DWG_Имя/Раздел_Комментарий.                              |
| **Связь IFC**                       | (98)\_IFC_Имя/Раздел_Комментарий.                              |
| **Связь NWC**                       | (95)\_NWC_Имя файла.                                           |

<note type="info">

**Как изменить рабочий набор элемента:**

Выберите элемент -> в палитре «Свойства» найдите параметр «Рабочий набор» -> выберите корректное значение.

Массовое изменение выполняйте только после проверки выбранных элементов.

</note>

## 5\. Запрещенные действия

<note>

**Запрещено стандартом проекта**

Размещать элементы, участвующие в оформлении документации, в рабочих наборах, начинающихся с «(50)\_». Наборы (50)\_Temp и (50)\_Имитация предназначены только для временных, скрываемых и имитационных объектов.

</note>

-  Создавать, удалять или переименовывать рабочие наборы без согласования с BIM-координатором.

-  Создавать дополнительные наборы без обязательного кода в имени.

-  Помещать несколько внешних связей в один рабочий набор или размещать связь в наборе основной геометрии.

-  Оставлять новые элементы в Workset1, «Рабочем наборе 1» или другом наборе, не предусмотренном структурой проекта.

-  Делать весь рабочий набор редактируемым без необходимости. Предпочтительно заимствовать конкретные элементы.

-  Обходить конфликт владения удалением, копированием или принудительным изменением чужих элементов.

-  Прерывать синхронизацию, закрывать Revit или отключать сеть во время записи в центральное хранилище.

-  Создавать отсоединенную копию или новое центральное хранилище без указания BIM-координатора.

## 6\. Синхронизация и освобождение элементов

1. Перед синхронизацией завершите активную команду и сохраните текущие изменения.

2. Выполните «Синхронизировать с файлом хранилища». В комментарии кратко укажите выполненную работу.

3. Выберите освобождение всех принадлежащих вам элементов и рабочих наборов.

4. После синхронизации убедитесь, что модель не сообщает о неотправленных изменениях.

5. В конце рабочего дня не оставляйте элементы занятыми без необходимости.

## 7\. Что делать при конфликте владения

| **Ситуация**                           | **Действие**                                                                                                                                                        |
|----------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Элемент занят другим пользователем** | Не создавайте дубликат. Свяжитесь с владельцем и попросите выполнить синхронизацию и освободить элемент.                                                            |
| **Пользователь недоступен**            | Передайте BIM-координатору имя владельца, ID элемента и текст сообщения Revit. Принудительное освобождение выполняет только ответственное лицо.                     |
| **Связь не загружается**               | Проверьте, открыт ли соответствующий рабочий набор (95)–(98), и доступен ли исходный файл.                                                                          |
| **Элементы оказались не в том наборе** | Остановите массовую работу, отфильтруйте созданные элементы, исправьте принадлежность и синхронизируйтесь. При большом объеме сообщите BIM-координатору.            |
| **Ошибка центрального хранилища**      | Не сохраняйте модель поверх центральной и не создавайте новый центральный файл самостоятельно. Зафиксируйте сообщение об ошибке и обратитесь к BIM-координатору/ИТ. |
