Подключение корпоративных плагинов pyRevit через Nextcloud

Корпоративные плагины Revit распространяются через **Nextcloud**.

После первоначальной настройки обновления плагинов будут автоматически загружаться на ваш компьютер.

## 1\. Необходимое ПО

Перед началом работы на компьютере должны быть установлены:

-  Autodesk Revit;

-  pyRevit;

-  [Nextcloud Desktop Client.](./nextcloud)

Если какое-либо из приложений отсутствует, обратитесь в ИТ-службу.

## 2\. Подключение Nextcloud

Шаг 1. Запустите Nextcloud

Откройте **Nextcloud Desktop Client**.

Если учётная запись Nextcloud ещё не подключена:

1. Нажмите **Войти / Log in**.

2. Укажите адрес корпоративного Nextcloud.

3. Выполните вход под своей корпоративной учётной записью.

4. Разрешите приложению доступ к Nextcloud.

Nextcloud Desktop создаёт на компьютере локальную папку и автоматически синхронизирует её содержимое с сервером.

## 3\. Синхронизация папки с плагинами

В настройках синхронизации необходимо выбрать корпоративную папку с плагинами pyRevit.

Например:

```
Nextcloud
└── Гарда - ТИМ – отдел
    └── 04_Плагины
		└── Garda-BIM
        	└── Garda BIM.extension
```

Рекомендуется синхронизировать только необходимую корпоративную папку, а не весь Nextcloud.

Nextcloud позволяет отдельно выбирать удалённую папку, которая должна синхронизироваться с компьютером.

<note>

**Важно!**

Папка с плагинами должна быть **полностью загружена на компьютер**.

</note>

Не рекомендуется использовать режим, при котором файлы существуют только в облаке и скачиваются при обращении.

Для папки с плагинами необходимо использовать обычную локальную синхронизацию или режим **«Всегда хранить на этом устройстве»**.

Nextcloud позволяет отключать режим виртуальных файлов для синхронизируемых папок.

После завершения синхронизации убедитесь, что папка открывается через Проводник Windows.

Например:

```
C:\Nextcloud\Гарда - ТИМ – отдел\04_Плагины\Garda-BIM\
```

Внутри неё должна находиться папка расширения:

```
Garda BIM.extension
```

## 4\. Подключение корпоративных плагинов в pyRevit

Запустите **Revit**.

Перейдите:

**pyRevit -> Settings**

Найдите раздел:

**Custom Extension Directories**

или

**Custom Extension folders**

Нажмите:

**Add folder**

и выберите папку, **внутри которой находится** `.extension`.

Например, если структура выглядит так:

```
C:\Nextcloud\Гарда - ТИМ – отдел\04_Плагины\Garda-BIM\
└── Garda BIM.extension
```

в pyRevit необходимо указать:

```
C:\Nextcloud\BIM\pyRevit
```

Важно

Нужно указывать:

```
✅ C:\Nextcloud\Гарда - ТИМ – отдел\04_Плагины\Garda-BIM\
```

а не:

```
❌ C:\Nextcloud\Гарда - ТИМ – отдел\04_Плагины\Garda-BIM\Garda BIM.extension
```

pyRevit ищет внутри указанной директории папки с окончанием `.extension`.

## 5\. Применение настроек

После добавления пути:

1. Сохраните настройки pyRevit.

2. Нажмите **pyRevit -> Reload**.

Либо полностью закройте и заново запустите Revit.

После перезагрузки в ленте Revit должна появиться вкладка с корпоративными инструментами.

## 6\. Проверка подключения

После настройки убедитесь, что:

-  Nextcloud запущен;

-  синхронизация завершена без ошибок;

-  папка с плагинами существует локально;

-  внутри неё присутствует папка с расширением `.extension`;

-  путь к родительской папке добавлен в **Custom Extension Directories** pyRevit;

-  после добавления пути выполнен **Reload**.

Пример правильной структуры:

```
Nextcloud
└── Гарда - ТИМ – отдел
    └── 04_Плагины
		└── Garda-BIM   				← этот путь подключаем в pyRevit
        	│
        	└── Garda BIM.extension
           	 	│
           	 	├── CorporateTools.tab
           	 	│   ├── BIM.panel
           	 	│   ├── COORD.panel
           	 	│   └── ...
           	 	│
           	 	├── lib
           	 	└── ...
```

Папки пользовательских расширений являются штатным механизмом pyRevit.

## Обновление корпоративных плагинов

Самостоятельно обновлять плагины **не требуется**.

Обновления публикуются централизованно и автоматически поступают в корпоративную папку Nextcloud.

Nextcloud Desktop автоматически синхронизирует изменения между сервером и локальным компьютером.

Схема обновления:

```
Корпоративный репозиторий
        ↓
     Nextcloud
        ↓
автоматическая синхронизация
        ↓
локальная папка пользователя
        ↓
      pyRevit
```

Если была обновлена существующая команда, новая версия будет загружена через Nextcloud автоматически.

Если были:

-  добавлены новые кнопки;

-  удалены кнопки;

-  добавлены новые панели;

-  изменена структура вкладки pyRevit,

необходимо выполнить:

**pyRevit -> Reload**

или перезапустить Revit.

## Запрещённые действия

Не следует:

-  изменять файлы внутри корпоративной папки плагинов;

-  переименовывать папку `.extension`;

-  перемещать корпоративную папку после её подключения в pyRevit;

-  удалять отдельные файлы или кнопки из расширения;

-  отключать синхронизацию папки в Nextcloud;

-  включать режим хранения файлов только в облаке.

Все изменения корпоративных плагинов выполняются централизованно.

## Если плагины пропали

В первую очередь необходимо проверить:

1. Запущен ли **Nextcloud Desktop Client**.

2. Нет ли ошибок синхронизации.

3. Существует ли локальная папка с плагинами.

4. Находится ли внутри неё папка `.extension`.

5. Сохранён ли путь в:

   **pyRevit -> Settings -> Custom Extension Directories**

6. Выполнить:

   **pyRevit -> Reload**

Если после этого корпоративная вкладка не появилась, обратитесь к BIM-координатору или в ИТ-службу.
